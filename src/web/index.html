≈ semcache semantic caching layer

Cache LLM answers by meaning.
Serve a wrong one never.

Exact-match caching misses every rephrased question; naive similarity caching serves confident wrong answers. semcache embeds each query, looks up its nearest cached entry, and lets a calibrated hit policy - not a magic threshold - decide whether serving is worth the risk. Everything below runs locally in your browser against a simulated helpdesk backend. No API keys, no servers, nothing leaves the page.
